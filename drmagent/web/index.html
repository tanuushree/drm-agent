Step 4 of 5

Run the pipeline

For each donor, DRM Agent will:

  1. Fetch matching Gmail threads
  2. Summarize the conversation history
  3. Extract a structured donor profile
  4. Classify the next relationship action
  5. Draft a plan, then apply a fixed approval policy
Ready when you are — this runs live LLM calls per donor.
